# Figures

Each figure is generated by a self-contained script here from a small CSV in `data/`; every CSV cites the
job ID(s) it was extracted from, and the primary logs live (hashed) in the durable archive
`/g/data/um09/as1708/gems-provenance/`. Regenerate any figure with `python3 figNN_*.py` (needs matplotlib;
on Gadi `module load python3/3.11.7`). Both PDF (vector, for the thesis) and PNG (preview) are written.
